Synoptic View

Tripartite Visualization

Method

This interface presents manuscript Q, the 1505 edition, and the 1553 redaction in parallel. The alignment is based on TEI correspondence markers and preserves both parallel and non-parallel structures.

The transition from the XML encoding to the web visualization was achieved through a JavaScript script that reads the TEI file, interprets its structure, and transforms the encoded data into an interactive HTML table.

Once the page is loaded, the script fetches the XML file, parses it, and identifies the textual units that correspond across the three witnesses by means of the @corresp attribute. These aligned units are then grouped and displayed side by side in three columns, one for each witness (Q, T1, and T16), thus generating the synoptic view.

The script also processes the TEI apparatus elements, such as <app>, <lem>, <rdg>, and <note>, converting them into interactive elements on the webpage: the main text remains readable, while the apparatus can be expanded and consulted when needed.
